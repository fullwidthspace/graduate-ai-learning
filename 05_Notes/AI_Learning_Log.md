## 我今天理解的新概念

### Conda Environment

不同项目可以使用不同的 Python 和软件包环境，避免项目之间产生版本冲突。

### Python Interpreter

VS Code 运行 Python 程序时实际使用的 Python。

### Jupyter Kernel

Notebook 执行代码时实际使用的 Python 环境。

### Git

用于记录代码版本。

git status
git add .
git commit -m "message"
